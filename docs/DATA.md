# Data and provenance

All bundled NBA and weather events are deterministic synthetic examples, not live events or historical real-world observations. They are labeled DEMO DATA on every product surface. A reference is a synthetic fixture benchmark for the same candidate outcome, not a real market quote. Forecasts are numerically specified fixtures rather than probabilities generated by an LLM. Historic resolutions are synthetic labels captured after their associated pre-event forecasts. No claim of real-world model validation can be derived from these fixtures.

A future real provider requires published endpoint documentation, permitted usage, rate limits, caching, capture timestamps, pre-start feature availability, and an explicit fallback to the demo data. A real sports model must split chronologically and audit standings, injuries, postgame stats, and reference timestamps against event starts.

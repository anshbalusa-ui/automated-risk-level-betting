# Product contract

An automated personalized **simulation-only** forecasting agent. Inputs: categories (Sports/NBA, Weather), interests, exactly Low/Medium/High risk, exactly Review/Auto-Simulate mode, starting 1,000 virtual credits. No real-money execution. Each event has explicit candidate outcome probabilities; the selected band targets only those candidates. Low [60%,100%], Medium [40%,60%), High [15%,40%); below 15% abstains. Evidence policy separately checks uncertainty, data quality/freshness, reference disagreement, and calibration. An included candidate is surfaced in Review or reserved as a virtual position in Auto-Simulate; resolution augments a historical snapshot and analytics compare all evaluated candidates against included candidates. Every seeded event/reference/result is DEMO DATA.

Navigation: `/` landing; `/onboarding` at most four steps; `/dashboard` activity and opportunities; `/forecast/[id]` model vs policy explanations; `/portfolio` virtual positions; `/history` decisions and results; `/performance` accuracy, Brier, calibration and breakouts. Preserve no-signup Try Demo as the primary entry point. All user-facing money-like quantities say credits or simulation units, never currency.
